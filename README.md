# Student Result Prediction — Practical 2

This project trains a reproducible machine-learning model to predict student results and automatically runs tests with GitHub Actions.

## Practical aim
Automatically train and test the model whenever the repository is updated.

## Files
- `train_model.py` generates a deterministic dataset of 300 student records, trains a StandardScaler + LogisticRegression pipeline, and writes the model and metrics.
- `student_results.csv` is generated by the training script.
- `student_result_model.pkl` is the serialized trained model.
- `metrics.json` records accuracy, train/test sizes, confusion matrix, features, and random seed.
- `test_ml_pipeline.py` contains automated pipeline tests.
- `.github/workflows/ml-ci.yml` runs training and tests on pushes and pull requests to `main`.

## Run locally
```bash
python -m pip install -r requirements.txt
python train_model.py
python -m unittest discover -v
```

## Result encoding
- `1` = PASS
- `0` = FAIL

The generated label is based on a weighted score: attendance 25%, internal marks 35%, assignment marks 20%, and previous score 20%. A weighted score of 60 or above is labelled PASS.

The dataset is synthetic and intended for practical/educational use, not real student assessment.
